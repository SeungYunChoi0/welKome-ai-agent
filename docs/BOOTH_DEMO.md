# 부스 화면과 시연 탭

2026-11-18 CO-SHOW 부스용 화면. 오른쪽 검색 패널과 바탕을 부스 벽에 맞춘 새 스킨이고, 휴대폰 화면 모양은 그대로다.

## 바뀐 것

| 항목 | 내용 |
|---|---|
| 스킨 | 검남색 벽, 천장 조명, 크림색 입체 제목, 말풍선 질문, 아래쪽 산수화 띠 (`frontend/static/style.css` 뒷부분) |
| 탭 | 홈 · **시연** · 챗봇. 맛집 탭은 화면에서 뺐다(서버의 `/restaurants`는 그대로) |
| 시연 탭 | 저장해 둔 질문 10개의 실제 기록을 휴대폰 대화와 검색 패널에 다시 재생하고, 끝나면 처음부터 반복한다. 서버·모델을 부르지 않는다 |
| 자동 전환 | 60초 동안 아무도 만지지 않으면 시연 탭으로 넘어간다(`demo.js`의 `IDLE_MS`) |
| 직접 질문 | 챗봇 탭에서 질문하면 시연 재생을 바로 끝내고 실제 서버로 답한다 |
| 글꼴 | `frontend/static/fonts/`에 내장. 부스에 인터넷이 없어도 같은 글꼴 |

## 실제 시연 기록 만들기 (한 번만)

지금 `frontend/static/demo_runs.json`은 **예시 데이터**다(휴대폰 아래에 「· 예시」 표시). 실제 서버가 있는 컴퓨터에서 아래를 한 번 실행하면 실제 답변과 실제 검색 기록으로 바뀐다.

```bash
bash run_demo.sh                         # 터미널 1: 서버 켜기 (http://127.0.0.1:8001)
python tools/record_demo.py              # 터미널 2: 질문 10개를 차례로 보내 기록 저장
```

- 생성 모델을 질문마다 두 번 안팎 부르므로 **유료 호출이 20회 안팎** 생긴다.
- 질문 하나에 30초~1분, 전체 5~10분.
- 결과는 `frontend/static/demo_runs.json`에 저장되고, 이전 파일은 `demo_runs.backup.json`으로 남는다. 저장 뒤 브라우저를 새로 고치면 「예시」 표시가 사라진다.
- 한 문항만 다시: `python tools/record_demo.py --only 3`
- 서버 포트가 다르면 `--url http://127.0.0.1:8000`.
- 질문 목록은 `tools/record_demo.py`의 `QUESTIONS`.

## 홈 화면 · 장소 사진 고르기

홈 위쪽의 사진 올리기 칸을 「장소 사진 고르기」로 바꿨다(`frontend/static/places.js`). ◀ ▶ 버튼이나 손가락으로 넘기면 멈춘 뒤 0.4초쯤에 아래 설명 카드와 실록 카드가 그 장소 정보로 바뀐다. 정보는 미리 받아 둔 `frontend/static/places.json`에서 읽으므로 서버를 부르지 않는다.

- 사진: 위키미디어 공용(CC0 · 퍼블릭 도메인 · CC BY · CC BY-SA), 출처는 `frontend/static/images/places/CREDITS.md`.
- 다시 받기: `python tools/record_places.py --url <서버 주소>` (사진마다 `/predict_image` 1회, 유료). 모델이 다른 이름으로 알아본 사진은 다음 후보로 바꾸고, 끝내 안 맞으면 그 장소를 뺀다.
- 한 장소만: `--only jongmyo`. 서버 없이 사진과 짧은 설명만: `--offline`.

## 시연 속도 조정 (`frontend/static/demo.js` 맨 위)

| 값 | 기본 | 뜻 |
|---|---|---|
| `IDLE_MS` | 60000 | 손대지 않으면 시연 탭으로 넘어가는 시간 |
| `PAUSE_MS` | 5000 | 답변을 보여 준 뒤 다음 질문까지 |
| `TYPE_MS` | 75 | 질문 한 글자 입력 간격 |
| `MAX_GAP_MS` | 2500 | 기록 속 대기가 이보다 길면 줄여서 재생(화면의 경과 시간 숫자는 기록 그대로) |
